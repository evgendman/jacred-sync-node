# Дорожная карта

Статусы отражают только подтверждённые результаты.

## 1. Первичная синхронизация — выполняется

- [ ] Дождаться `sync: end`, проверить ошибки и количество обработанных записей.
- [ ] Проверить сохранение FileDB и контрольных точек.
- [ ] Перезапустить службу и убедиться, что sync продолжает работу от сохранённого состояния.
- [ ] Проверить следующий инкрементальный цикл.

## 2. Проверка метаданных

- [ ] Выбрать несколько одинаковых записей на родительском и локальном узлах по infohash/magnet.
- [ ] Сравнить наличие и содержимое `ffprobe`.
- [ ] Сравнить `voices` и `languages`; определить, какие поля копируются, а какие рассчитываются локально.
- [ ] Проверить, обновляется ли локальный `ffprobe`, если он уже был заполнен.
- [ ] Проверить сохранность после рестарта и зафиксировать результаты в [документе проверки](docs/ffprobe-and-voices.md).

## 3. Включить локальный Tracks worker

- [ ] Только после завершения этапа 1 установить `tracks=true`.
- [ ] Проверить `tsuri=http://127.0.0.1:8097`, логи, анализ тестовой раздачи и сохранение результата.
- [ ] Проверить уникальную категорию `jacred-mini-9117`.
- [ ] Убедиться, что системный cron парсеров по-прежнему отключён.

## 4. Проверить локальный API и интеграции

- [ ] Проверить health и API поиска/Torznab.
- [ ] Проверить категории и доступные метаданные.
- [ ] Подключать Prowlarr только после проверки локального API.
- [ ] Убедиться, что `opensync=false` и локальный Sync API не открыт другим узлам.

## 5. Сопровождение

- [ ] Добавить минимальный проверенный патч/обёртку установщика, пропускающий cron.
- [ ] Описать обновление с сохранением конфигурации и базы.
- [ ] Описать резервное копирование и восстановление.
- [ ] Перед обновлениями проверять изменения upstream и поведение установщика.
