# Архитектура

Локальный JacRed получает данные с родительского узла и предоставляет локальный API. Самостоятельный разбор трекеров не является задачей этого экземпляра.

| Компонент | Значение |
|---|---|
| Установка | `/opt/jacred` |
| systemd unit | `jacred.service` |
| Пользователь процесса | `jacred` |
| Runtime config | `/opt/jacred/init.conf` |
| HTTP port | `9117` |
| Sync API | `https://sync.jacred.stream` |
| TorrServer для Tracks | `http://127.0.0.1:8097` |
| Tracks category | `jacred-mini-9117` |

## Поток

1. Sync worker запрашивает конфигурацию родителя.
2. FileDB загружается партиями; Spidr синхронизируется отдельным потоком.
3. Записи объединяются с локальной FileDB.
4. Некоторые метаданные, включая `voices` и `languages`, могут пересчитываться локальной логикой.
5. После первичной синхронизации планируется включить локальный Tracks worker.

`syncapi` — источник, с которого мы получаем данные. `opensync=false` запрещает другим узлам забирать Sync API с нашего экземпляра, но не мешает исходящей синхронизации. Пропуск системного cron парсеров не равнозначен отключению внутренних worker'ов JacRed.

Upstream: https://github.com/jacred-fdb/jacred
