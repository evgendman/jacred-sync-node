# Установка

## Текущее развёртывание

Использован официальный Linux amd64 release asset JacRed. Приложение установлено в `/opt/jacred`, systemd unit — `/etc/systemd/system/jacred.service`, системный пользователь — `jacred`, порт — `9117`. Runtime config: `/opt/jacred/init.conf`.

## Отличие от стандартного установщика

Официальный установщик был скопирован в `/tmp/jacred-upstream.sh`; временная изменённая копия находилась в `/tmp/jacred-sync-only.sh`. Из последовательности установки пропущен вызов `install_cron`, остальные этапы установки приложения и службы оставлены. Snapshot не загружался.

Временные скрипты пока не добавлены в репозиторий. До публикации повторяемого установочного сценария нужно восстановить и проверить минимальный патч к актуальному upstream. Не запускать стандартный установщик вслепую: он может снова установить расписание парсеров.

## Snapshot

На 12 октября 2026 года `https://sync.jacred.stream/latest.tar.zst.zip` возвращал HTTP 404, тогда как Sync API выдавал данные. Это наблюдение на дату проверки; перед новой установкой URL следует проверить повторно.

## Проверки после установки

Подтверждены `systemctl is-active jacred` → `active` и HTTP 200 от `curl http://127.0.0.1:9117/health`. Первичная синхронизация была начата, но её завершение ещё не подтверждено.

## Обновления

Процедура обновления пока не автоматизирована. Перед обновлением сохранить runtime config и данные, проверить изменения upstream установщика и убедиться, что cron парсеров не включится. Не публиковать рабочий config, базу и логи.
