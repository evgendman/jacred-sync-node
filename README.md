# JacRed Sync Node

Документация локального экземпляра JacRed, который получает базу от родительского сервера. Это не форк upstream-кода, а описание нашего развёртывания, конфигурации, проверок и планов.

> **Статус на 12 октября 2026:** сервис установлен и запущен, `/health` отвечал HTTP 200. Первичная синхронизация началась, но её завершение и проверка метаданных пока не подтверждены.

## Назначение

- Синхронизация с `https://sync.jacred.stream`.
- Локальный API на порту `9117`.
- Без автономного разбора трекеров через системный cron.
- После первичной синхронизации — проверка локального Tracks worker и полей `ffprobe`, `voices`, `languages`.

## Текущая схема

```text
https://sync.jacred.stream
       | Sync API (FileDB / Spidr)
       v
Локальный JacRed :9117
       |-- локальная FileDB и API
       +-- Tracks worker (пока tracks=false)
               +-- TorrServer http://127.0.0.1:8097
```

## Уже сделано

Установлен официальный Linux amd64 release asset в `/opt/jacred`, создан systemd unit `jacred.service`, runtime-конфигурация находится в `/opt/jacred/init.conf`. Временная копия установщика пропускала этап установки системного cron парсеров. Sync API настроен на родительский сервер; `tracks=false` оставлено до завершения первоначальной синхронизации.

В журнале 12 октября наблюдались первые две партии по 2001 запись с `nextread=True`. Это подтверждает начало синхронизации, но не её завершение.

## Безопасность

Не коммитить рабочий `init.conf`, каталог `Data/`, базу, логи, резервные копии или секреты. Не запускать стандартный установщик при обновлении, пока не проверено, что он не включит cron парсеров. Upstream: https://github.com/jacred-fdb/jacred
