# JacRed Sync Node

Документация локального экземпляра JacRed, который получает базу от родительского сервера. Это не форк upstream-кода, а описание нашего развёртывания, конфигурации, проверок и планов.

> **Статус на 13 октября 2026:** первичная синхронизация завершилась и сохраняет контрольные точки. Проверено совпадение `ffprobe` локального и публичного API для одной конкретной раздачи. При этом инкрементальная синхронизация сейчас не работает: `sync.jacred.stream` возвращает `403 Forbidden`. До исправления ошибки свежесть локальной базы не гарантируется.

## Назначение

- Получение базы JacRed от `https://sync.jacred.stream`.
- Локальный API на порту `9117`.
- Использование локального JacRed медиасервером и интеграциями, чтобы обычные поисковые запросы шли к локальному API, а не каждый раз к публичному серверу.
- Без автономного разбора трекеров через системный cron.
- `tracks=false`: локальный Tracks worker пока отключён; сначала нужно восстановить синхронизацию и проверить полноту метаданных.

## Текущая схема

```text
https://sync.jacred.stream
       | Sync API (FileDB / Spidr)
       v
Локальный JacRed :9117
       |-- локальная FileDB и локальный API для поиска
       +-- Tracks worker (отключён: tracks=false)
               +-- TorrServer http://127.0.0.1:8097
```

## Подтверждённые результаты

- Установленный локальный runtime: `3.18.0-oss`, Git SHA `c207d0d4`, build date `2026-10-12 07:38:51 UTC`.
- Первичный цикл завершился с `nextread=False`; журнал содержал `sync: end`, состояние было сохранено в `starsync.txt`. Контрольные точки `lastsync.txt` и `starsync.txt` наблюдались со значением `134363012594519837`.
- В статистике локальной базы было просканировано 3 624 648 записей FileDB и найдено 838 837 уникальных infohash с непустыми `ffprobe`. Для этого результата `fromTorrentDb=838837`, `fromTracksFiles=0`, `fromMemory=0`, `filesScanned=0`, ошибки чтения базы и magnet равны нулю. Это указывает на широкое покрытие метаданными из FileDB, а не на локальный массовый анализ файлов.
- Для контрольной раздачи фильма **«В потерянных землях / In the Lost Lands»** (infohash `814ce3359c22bcfe53bbbdbc8d5287c0133b8beb`) локальный и публичный API вернули один и тот же релиз и идентичные пять потоков `ffprobe`: H.264 1920×800, AC-3 2.0 с названием `MVO | zaKADRY`, E-AC-3 5.1 `Original` и две английские дорожки субтитров `Full` и `SDH`. Совпали языки `rus/eng` и качество `1080`.
- В той же проверке публичный ответ содержал пустой `voices`, а локальный — `["заКАДРЫ"]`. Это согласуется с тем, что список озвучек может рассчитываться/обогащаться локально на основании названия релиза и аудиодорожек; поля `voices` не следует считать побайтно идентичными между узлами.

**Рабочий вывод:** с высокой вероятностью локальная FileDB содержит нужные данные публичного JacRed, включая `ffprobe`, а локальный API пригоден как основной поисковый источник для медиасервера. Это снижает необходимость делать частые поисковые запросы к публичному API и уменьшает риск ограничений из-за их частоты. Полная идентичность всех записей не доказана: точное сравнение выполнено для одной записи, поэтому дополнительные контрольные примеры остаются в roadmap. Локальный узел всё ещё зависит от родительского сервера для обновления базы; из-за текущего `403` её актуальность не гарантирована.

## Эксплуатационные решения

- Использовать локальный endpoint `http://127.0.0.1:9117/api/v2.0/indexers/all/results`, если медиасервер/адаптер работает на том же хосте. Из контейнера или с другого хоста нужно использовать адрес, доступный из соответствующего сетевого пространства; не предполагать, что контейнерный `127.0.0.1` указывает на хост.
- Не включать локальный Tracks worker и массовый `ffprobe` без отдельной необходимости: значительная доля записей уже имеет метаданные.
- После устранения ошибки синхронизации проверить продвижение контрольной точки и успешный инкрементальный цикл.
- Использовать локальный JacRed вместо прямого частого поиска на публичном узле — это уменьшает количество поисковых обращений к публичному API, но не является абсолютной гарантией отсутствия любых ограничений.

## Безопасность

Не коммитить рабочий `init.conf`, каталог `Data/`, базу, логи, резервные копии или секреты. Не запускать стандартный установщик при обновлении, пока не проверено, что он не включит cron парсеров. Upstream: https://github.com/jacred-fdb/jacred
